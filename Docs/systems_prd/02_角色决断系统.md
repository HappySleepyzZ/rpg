# 角色决断系统

## 1. 系统定位

角色决断系统是一套规则驱动的叙事决策模型。

它用于处理非主控角色在关键剧情节点上的自主选择。

核心原则：

> 玩家可以影响角色，但不应直接替角色决定人生。

本系统适用于同伴具有强主体性的剧情 RPG。尤其适合以下情况：

- 主角是唯一可控角色。
- 队友或 NPC 拥有独立情感线和个人结局。
- 故事主题强调自由意志、自我认同或反对操控。
- 角色结局不应由玩家一句选项直接决定。

## 2. 与传统分支的区别

传统做法：

```text
玩家选择 A：角色留下
玩家选择 B：角色离开
```

角色决断系统：

```text
玩家长期影响角色的认知、创伤、信任、自我与牵绊。
关键节点时，角色根据自身状态自行决定留下或离开。
玩家在高信任条件下可以请求、劝说或质问，但不能完全代替角色选择。
```

这样能让角色更像独立的人，而不是玩家意志的延伸。

## 3. 决断资料

每个关键角色拥有一份 `DecisionProfile`。

```text
DecisionProfile {
  character_id
  core_wound
  core_desire
  fear
  attachment_targets[]
  autonomy_need
  temptation
  taboo
  decision_axes[]
}
```

字段说明：

- `core_wound`：核心创伤。
- `core_desire`：最深层渴望。
- `fear`：最害怕发生的事。
- `attachment_targets`：强牵绊对象，可以是人物、组织、故乡、使命、信仰。
- `autonomy_need`：该角色需要从什么身份或关系里获得自我。
- `temptation`：关键时刻最容易诱惑角色走向失控的东西。
- `taboo`：角色最不能接受的行为或状态。
- `decision_axes`：用于判定关键选择的变量轴。

## 4. 通用决断变量

角色可使用以下变量进行判定：

```text
selfhood        自我强度
attachment      牵绊强度
resentment      怨恨
guilt           罪疚
dependency      依赖
truth_known     真相掌握
trust_player    对玩家信任
world_alignment 世界路线倾向
promise_weight  强承诺权重
crisis_pressure 当前危机压力
```

变量不需要全部显式显示给玩家，但必须能通过剧情反馈被理解。

## 5. 介入权

玩家能否影响非主控角色的关键选择，取决于介入权。

介入权由关系系统提供。

```text
低介入：玩家只能旁观。
中介入：玩家可以表达立场。
高介入：玩家可以提出请求。
强介入：玩家拥有终局约定或关键承诺。
```

介入权不是控制权。

即使拥有强介入，角色也可能拒绝玩家，但系统应给予该介入足够高的判定权重。

## 6. 决断节点结构

每个关键决断节点应包含：

```text
DecisionNode {
  id
  character_id
  context
  options_by_character[]
  player_interventions[]
  conditions[]
  result_priority[]
  feedback_hooks[]
}
```

字段说明：

- `context`：当前情境。
- `options_by_character`：角色可能作出的选择。
- `player_interventions`：玩家可用介入选项。
- `conditions`：每个结果的判定条件。
- `result_priority`：条件冲突时的优先级。
- `feedback_hooks`：结果前后的提示、台词、演出、UI 状态变化。

## 7. 判定示例

抽象场景：

一名同伴面对旧日牵绊对象的邀请。该邀请能满足同伴最深层的依附，但会让他失去自我。

可能判定：

```text
if dependency 高 and attachment 高 and selfhood 低:
  接受邀请，被旧关系吞没

elif selfhood 高 and truth_known 充分 and player 曾多次支持自主:
  拒绝邀请，选择自己的道路

elif resentment 高 and attachment 低:
  激烈切断关系，获得自由但留下创伤

elif attachment 高 and selfhood 高:
  承认关系重要，但拒绝继续被定义
```

这类判定能生成比“接受/拒绝”更丰富的结果。

## 8. 状态反馈

角色决断不能是黑箱。

玩家需要在过程中感到：

> 这个结果是我长期互动影响出来的，而不是系统突然裁定。

反馈方式：

- 角色台词变化。
- 战斗技能或协作行为变化。
- 关系界面状态词变化。
- 梦境、回忆、独白变化。
- 章节结算提示。
- 同伴对玩家介入的回应。

示例状态词：

```text
动摇
依附
清醒
逃避
自责
觉醒
拒绝被定义
仍被旧债牵引
```

状态词应比数值更适合玩家理解。

## 9. 决策优先级

建议优先级：

```text
1. 不可逆锁定状态
2. 角色核心禁忌
3. 已揭露真相
4. 强承诺
5. 自我强度
6. 牵绊强度
7. 玩家介入
8. 世界路线倾向
9. 当前危机压力
```

说明：

- 不可逆状态包括死亡、公开决裂、永久污染、誓约、关键 NPC 消失等。
- 核心禁忌应优先于普通好感，否则角色会失去可信度。
- 强承诺权重高，但不应无视角色人格。

## 10. 设计风险

### 风险一：玩家觉得失控

解决：

- 提前提供状态反馈。
- 在关键节点前给出补救机会。
- 让角色解释自己的决定。

### 风险二：角色像公式

解决：

- 每个角色拥有不同权重。
- 同一标签对不同角色效果不同。
- 决断结果配套专属文本和演出。

### 风险三：玩家误以为有正确答案

解决：

- 不把结局命名为简单的好坏。
- 让不同结果都有代价和成立理由。
- 避免所有角色都能被完美拯救。

## 11. 最小可行版本

MVP 建议：

```text
关键自主角色：3 到 4 名
每名角色：2 到 3 个重大决断节点
通用变量：selfhood / attachment / truth_known / trust_player
介入等级：旁观、表达、请求、强承诺
状态反馈：关系界面 + 关键台词
```

先让少数角色真正“自己做决定”，比铺开大量浅层同伴更有价值。
