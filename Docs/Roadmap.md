- `[ ]`：未开始

## 技术原则

[x] 项目结构保持简单
[x] `Content` 下不额外套 `RPG` 包装目录
[x] 稳定系统优先用 C++
[x] 参数调试、关卡摆放、表现层优先用 Blueprint
[x] 游戏数值先用 DataAsset 管理
[x] 战斗调度保持可替换，半即时后续可改回合制
[x] 输入系统统一使用 Enhanced Input
